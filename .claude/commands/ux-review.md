Run a UI/UX review for Language Steps. Do not change code in this command.
1. Research (web search, 20 minutes maximum): what changed in the last 6 months in Duolingo, Lingopie, Busuu and Babbel, and any new guidance on designing for autistic or ADHD users (for example gov.uk accessibility guidance, WCAG updates). Write 10 lines maximum, each with a source link.
2. Audit: for every tab screen and the lesson template, check CLAUDE.md section 3: one primary action, no emoji, consistent components, touch targets, text amount per screen, and the 5 autism-friendly criteria (short, slow or clear, low sensory load, visual support, subtitles) where they apply. Run node tests/smoke.js and include its design checks.
3. Usage: query what I used in the last 60 days if the owner provides the database access; otherwise ask me which features I have not used. List features to consider removing.
4. Proposals: 3 to 5 ranked changes. For each: problem, evidence, proposed change, which screen, expected effect, effort (small, medium, large).
Say which proposals need a wireframe on the design canvas before any code.
