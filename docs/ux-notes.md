# UX notes from real use

After each UI change, run the 5-task script on your phone and note anything confusing. `/retro` and `/ux-review` read this file.

The 5 tasks: 1. start the next lesson · 2. answer one quiz question · 3. save a word from a story · 4. play one story line in the player · 5. open a travel situation and its Tips tab.

Format: `- date · task number · what happened · how it felt (one word) · idea`
